# Consultas

## 1. Objetivo

O saldo mostra quanto a conta tem. O extrato lista as entradas e saídas de um período. Pelo extrato, o titular pode abrir o comprovante de uma movimentação.

## 2. Operações

| Operação | Finalidade |
| --- | --- |
| [Consulta de saldo](saldo.md) | Consultar a posição atual a partir dos lançamentos confirmados. |
| [Comprovante](comprovante.md) | Recuperar a confirmação de uma movimentação individual. |
| [Extrato por período](extrato.md) | Conferir os lançamentos ordenados de um período. |
