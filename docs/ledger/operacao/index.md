# Operação

## 1. Objetivo

Aqui ficam os registros de auditoria, as regras para conferir saldos e lançamentos e as condições para voltar a aceitar movimentações depois de restaurar um backup.

## 2. Operações

| Operação | Resultado |
| --- | --- |
| [Consultar auditoria](auditoria.md) | O registro informa quem executou a ação e qual foi o resultado. |
| [Conciliar histórico e saldo](conciliar.md) | A verificação informa o conjunto analisado e as divergências encontradas. |
| [Validar recuperação](validar-recuperacao.md) | Conferir até que horário os dados foram recuperados e quais contas podem voltar a movimentar saldo. |

## 3. Disponibilidade

A auditoria, a conciliação e a liberação após restore exigem permissões próprias no ambiente. O titular consulta os lançamentos de suas contas no extrato.
