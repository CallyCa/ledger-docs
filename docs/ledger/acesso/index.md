# Acesso

## 1. Objetivo

O Ledger verifica qual usuário fez o pedido e se ele tem acesso à conta. Para ações como estornar uma transferência ou liberar movimentações depois de um restore, verifica também a permissão específica no ambiente.

## 2. Operações

| --- | --- |
| [Permissões por operação](permissoes.md) | Quem pode consultar contas, transferir, estornar ou liberar movimentações após restore. |
| [Atribuir titular a conta antiga](atribuir-titular.md) | Operador com permissão específica. |
